# MaynorAI 文章同步助手

一篇文章，同步到多个平台草稿箱，不用退出登录。专为 OPC｜一人公司打造：在编辑器里写好文章，通过浏览器扩展同步到微信公众号、知乎、CSDN、哔哩哔哩、什么值得买、GitHub 等 23 个平台的草稿箱；同一平台也可以添加多个账号。默认只创建或更新草稿；若在编辑器打开「同步后直接发布」，才会尝试发布。X 长文即使打开该开关，也不会自动点击发布。账号和 Cookie 只留在这台电脑上，不会上传到网站。

- 编辑器：https://editor.maynor1024.live/

- 扩展安装包：https://editor.maynor1024.live/MaynorAI-article-sync-extension.zip

## 三步开始使用

Edge 用户可从 Microsoft Edge 商店安装，其他浏览器请下载官方安装包并在 Chrome 中加载。在浏览器里登录各目标平台；若要做矩阵号，用隐私窗口添加账号，不必退出当前登录（需允许扩展在 InPrivate / 隐私窗口中运行）。然后登录 MaynorAI 编辑器，写作并同步为草稿。

![安装教程](https://product.maynor1024.live/docs/install.png)


## 使用介绍

在 [MaynorAI 编辑器](https://editor.maynor1024.live/) 写好文章后，可以保存到云端文章夹，并用本机浏览器扩展同步到各平台草稿箱。写作、保存草稿和同步到草稿箱是免费的；「AI 润色」「文章插图」和「做封面」需要付费。更完整的图文说明见产品页的[使用介绍](https://product.maynor1024.live/#guide)。

### 安装并连接浏览器扩展

打开工作台后，点顶部的「扩展连接」，按侧栏说明安装。账号和 Cookie 只留在你自己的浏览器里。

![扩展连接](https://product.maynor1024.live/docs/howto/07-extension.gif)

### 登录，用云端文章夹

登录后，左侧「云端文章夹」会加载你的云端文章。点左侧标题「云端文章夹」可以刷新列表。

![云端文章夹](https://product.maynor1024.live/docs/howto/01-library.gif)

### 写作、预览和保存

可以用 Markdown 写作，随时切到「预览」看排版。写完后点「保存草稿」。

![写作、预览和保存](https://product.maynor1024.live/docs/howto/02-writing.gif)

### 用 AI 润色正文

点工具栏「AI 工具」里的「AI 润色」，选择模型并写下要求后再开始。当前可选 Claude Opus 5.5、GPT-6.2 Sol、Gemini 4 Hydrogen、Grok 4.7。

![AI 润色](https://product.maynor1024.live/docs/howto/03-ai-polish.gif)

### 做封面和文章插图

在「AI 工具」里打开「做封面」或「文章插图」。做封面时可填写文案或上传参考图，再点生成。

![做封面](https://product.maynor1024.live/docs/howto/04-cover.gif)

### 同步到各平台草稿箱

扩展已连接、文章已保存后，点「同步到草稿箱」，勾选平台和账号后再创建任务。默认只创建或更新草稿。

![同步到草稿箱](https://product.maynor1024.live/docs/howto/05-sync.gif)

### 查看同步历史

点工具栏「同步任务」，打开侧栏「历史任务」，查看最近的同步结果。

![历史任务](https://product.maynor1024.live/docs/howto/06-history.gif)

## 功能特性

同一平台多个账号一起同步且不用退出登录、一次勾选多个平台、公众号排版适配与自动封面、任务历史与失败重试，以及本机优先的凭证保存。默认同步为草稿；若打开「同步后直接发布」，才会尝试发布。发布前仍建议在各平台后台核对。

微信公众号、知乎、CSDN、哔哩哔哩、什么值得买支持用隐私窗口添加账号；GitHub 用 Token 管理多个账号。其他平台仍使用当前浏览器中的登录态。

![功能特性](https://product.maynor1024.live/docs/features.png)

## 支持的平台

目前可同步到 23 个平台的草稿箱，持续扩展中：微信公众号、知乎专栏、什么值得买、掘金、CSDN、微博、百家号、博客园、头条、51CTO、简书、思否、开源中国、哔哩哔哩专栏、网易号、腾讯云开发者社区、抖音长文、抖音图文、小红书长文笔记、小红书图文笔记、阿里云开发者社区、GitHub、X 长文。

其中微信公众号、知乎、CSDN、哔哩哔哩、什么值得买和 GitHub 支持同一平台多账号。
