一篇文章，发到你的整个矩阵

MaynorAI 文章同步助手帮你把同一篇文章写入多个平台、多个账号的草稿箱。主号可以继续登录，再用隐私窗口添加矩阵号，不必先退出。

核心能力：

  1. 一次勾选多个平台，以及同一平台下的多个账号。
  2. 用隐私窗口添加账号，不用退出当前登录。
  3. 默认只创建或更新草稿，发布前仍由你在平台后台核对。
  4. 账号和 Cookie 只留在这台电脑上，不会上传到网站。

安装教程

三步开始使用

支持 Chrome、Edge 等 Chromium 内核浏览器。请先登录编辑器再同步，平台账号不必交给网站。

1

安装扩展

下载扩展安装包并解压。在 Chrome 打开 chrome://extensions（Edge 为 edge://extensions），开启「开发人员模式」，选择「加载已解压的扩展程序」。若要添加矩阵账号，请允许扩展在无痕 / InPrivate 窗口中运行。

2

登录平台，或添加矩阵账号

在浏览器中正常登录各平台网页端。若要在同一平台添加更多账号，使用「在隐私窗口添加账号」，不必退出当前登录。凭据只保存在这台电脑的扩展里。

3

登录编辑器并同步

打开并登录 MaynorAI 编辑器，写好文章后点击「同步到草稿箱」，勾选平台和账号。文章会以草稿形式写入各平台，检查排版后再手动发布。

功能特性

为矩阵账号准备的草稿工作台

在 MaynorAI 编辑器里一次写好，再同步到多个平台、多个账号的草稿箱，不用为切换账号而退出登录。

矩阵多账号，不用退出登录

微信公众号、知乎、CSDN、哔哩哔哩、什么值得买可用隐私窗口添加账号，当前登录不用退出；GitHub 用 Token 管理多个账号。适合一个人养矩阵号。

一键同步到 23 个平台

在编辑器中勾选目标平台和账号，一次提交即可把同一篇文章写入多个草稿箱，节省大量重复粘贴和排版时间。

公众号排版与自动封面

将 Markdown 转为更适合公众号的富文本，并尽量用封面图或正文第一张图自动补上草稿封面。建议仍在公众号后台预览后再发布。

账号和 Cookie 留在本机

扩展复用你已在网页端登录的会话。矩阵账号的 Cookie 或 GitHub Token 只保存在这台电脑的扩展里，不会上传到 MaynorAI 网站。

同步历史追踪

每次同步结果都会记入历史任务。你可以查看各平台状态，并对失败项直接重试或再次发送。

先存草稿，核对后发布

默认只创建或更新草稿，不会直接发布。请到各平台后台检查标题、排版和图片，确认无误后再发布。

本机扩展连接说明

在同一台电脑上打开浏览器和编辑器。扩展只在本地工作，连接密钥生成并保存在插件里。更完整的图文步骤，请查看编辑器中的安装指引。

本机连接
01

下载并加载扩展

下载官方 ZIP 并解压，在 Chrome 116+ 或 Edge 中以开发人员模式加载已解压的文件夹。添加矩阵账号前，请允许扩展在无痕 / InPrivate 窗口中运行。

02

登录平台，或添加矩阵账号

先打开需要同步的平台网页并完成登录。若要添加更多账号，使用隐私窗口，不必退出当前登录，也不必填写账号密码给 MaynorAI。

03

登录编辑器并完成检测

打开并登录编辑器，点击「扩展连接」或「重新检测」。显示已连接后，即可把文章同步为草稿。

          使用方式
          
两种触发场景

          
无论是刚写完的新文章，还是想对历史任务重试或补发，都有对应的使用路径

        

        

          

            

              

                
              

              
场景一：写完即同步在 MaynorAI 编辑器中完成并发送草稿

            

            
    
              
  1. 1在编辑器中写好标题和正文，必要时先预览排版
    2. 
              
  2. 2点击「同步到草稿箱」，勾选目标平台，以及同一平台下的多个账号
    3. 
              
  3. 3创建同步任务，各账号保存为草稿，再到后台核对后发布
    4. 
            

          

          

            

              

                
              

              
场景二：从历史任务重试或补发在同步历史中查看结果并再次发送

            

            
    
              
  1. 1打开编辑器中的历史任务，查看各平台成功或失败原因
    2. 
              
  2. 2对失败项直接重试，或重新选择平台和账号再次同步
    3. 
              
  3. 3确认新的结果写入历史后，到对应平台草稿箱检查并发布
    4.

    3.
