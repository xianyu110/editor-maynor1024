把一篇 Markdown 同步到二十个平台草稿箱

MaynorAI 文章同步助手是一款本地优先的多平台写作工具。你在编辑器中完成标题和正文，由已安装的浏览器扩展复用当前登录态，把文章保存到各平台草稿箱。

核心能力：

  1. 一次勾选多个目标平台，减少重复粘贴。
  2. 默认只创建或更新草稿，发布前仍由你在平台后台核对。
  3. 登录凭据留在浏览器，不必向网页提交平台账号密码。
  4. 可在历史任务中查看结果，并对失败项重试。

安装教程

三步开始使用

无需注册，安装扩展后即可使用。支持 Chrome、Edge 等 Chromium 内核浏览器。

1

安装扩展

下载扩展安装包并解压。在 Chrome 打开 chrome://extensions（Edge 为 edge://extensions），开启「开发人员模式」，选择「加载已解压的扩展程序」。

2

登录各平台

在浏览器中正常登录微信公众号、知乎、CSDN、哔哩哔哩专栏等平台网页端。扩展会读取当前浏览器的登录状态，无需输入任何账号密码，凭据不离开你的浏览器。

3

同步到草稿箱

打开编辑器写好文章，点击「同步到草稿箱」，勾选目标平台并创建任务。文章会以草稿形式写入各平台，检查排版后再手动发布。

功能特性

为多平台创作者准备的草稿工作台

在 MaynorAI 编辑器里一次写好，再同步到已登录平台的草稿箱，减少重复排版和来回粘贴。

一键多平台同步

在编辑器中勾选目标平台，一次提交即可把同一篇文章写入多个草稿箱，节省大量重复操作时间。

公众号排版适配

将 Markdown 转为更适合公众号的富文本，代码块和图片会按规则处理；建议仍在公众号草稿中预览后再发布。

登录凭据留在浏览器

扩展复用你已在网页端登录的会话，不必向 MaynorAI 提交平台 Cookie 或账号密码。

云端文章夹与本地草稿

登录编辑器后，可以把文章保存到你的云端文章夹；未登录时草稿仍可先留在本机，随时继续编辑。

同步历史追踪

每次同步结果都会记入历史任务。你可以查看各平台状态，并对失败项直接重试或再次发送。

先存草稿，核对后发布

默认只创建或更新草稿，不会直接发布。请到各平台后台检查标题、排版和图片，确认无误后再发布。

本机扩展连接

多平台草稿箱

编辑器通过本机浏览器扩展完成同步。扩展使用你已有的网页登录态，不会把平台 Cookie 交出去。需要逐步说明时，可直接打开编辑器查看实时安装与连接指引。

  1. 01
    先检查扩展与登录状态确认扩展已连接，并查看目标平台是否已在浏览器中登录。
  2. 02
    在编辑器提供文章并同步写好标题和 Markdown / HTML 正文，勾选平台后创建同步任务。
  3. 03
    查询结果，核对平台草稿在历史任务中查看各平台结果，再到平台后台核对并发布。

本机扩展连接说明

在同一台电脑上打开浏览器和编辑器。扩展只在本地工作，连接密钥生成并保存在插件里。更完整的图文步骤，请查看编辑器中的安装指引。

本机连接
01

下载并加载扩展

下载官方 ZIP 并解压，在 Chrome 116+ 或 Edge 中以开发人员模式加载已解压的文件夹。

02

在浏览器登录平台

先打开需要同步的平台网页并完成登录。扩展会复用当前会话，不必填写账号密码。

03

回到编辑器完成检测

打开编辑器，点击「扩展连接」或「重新检测」。显示已连接后，即可把文章同步为草稿。
